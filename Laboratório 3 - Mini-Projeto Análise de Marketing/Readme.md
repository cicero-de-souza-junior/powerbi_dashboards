# English Version (EN)

## Marketing Data Analysis - Power BI

### Overview

This repository contains a marketing data analysis project developed in Power BI. This project was carried out as part of the Microsoft Power BI for Business Intelligence and Data Science course by Data Science Academy. The project includes interactive dashboards that analyze different aspects of marketing data.

### Features

- **Customer View**: Detailed visualization of customer data, including total customers by education level and total purchases on the website.
- **Spending Behavior**: Analysis of how annual salary and the presence of children or teenagers at home influence customer spending.
- **Marketing Campaign Performance**: Evaluation of the effectiveness of marketing campaigns, with results segmented by gender and number of children.
- **Purchase Patterns by Point of Sale**: Analysis of spending in different categories by country and total spending by year and country.

### Usage

To use this project:

1. Clone this repository.
2. Open the files in Microsoft Power BI.
3. Use the interactive elements to filter the data as needed.

### Contribution

Feel free to fork this project and contribute by submitting pull requests or opening issues for any bugs found or suggested improvements.

Thank you for visiting this repository!

# Versão em Português (PT-BR)

## Análise de Dados de Marketing - Power BI

### Visão Geral

Este repositório contém um projeto de análise de dados de marketing desenvolvido no Power BI. Este projeto foi realizado como parte do curso Microsoft Power BI Para Business Intelligence e Data Science da Data Science Academy. O projeto inclui dashboards interativos que analisam diferentes aspectos dos dados de marketing.

### Funcionalidades

- **Visão Cliente**: Visualização detalhada dos dados dos clientes, incluindo total de clientes por grau de escolaridade e total de compras no site.
- **Comportamento de Gasto**: Análise de como o salário anual e a presença de filhos ou adolescentes em casa influenciam os gastos dos clientes.
- **Performance das Campanhas de Marketing**: Avaliação da efetividade das campanhas de marketing, com resultados segmentados por gênero e número de filhos.
- **Padrões de Compra por Ponto de Venda**: Análise dos gastos em diferentes categorias por país e os gastos totais por ano e país.

### Uso

Para utilizar este projeto:

1. Clone este repositório.
2. Abra os arquivos no Microsoft Power BI.
3. Utilize os elementos interativos para filtrar os dados conforme necessário.
